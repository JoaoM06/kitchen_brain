# Documentos

Central de requisitos, artefatos gerados e pesquisas usadas pelo time.

## Organização
| Tipo | Arquivos | Uso |
| --- | --- | --- |
| Requisitos funcionais | `REQUISITOS FUNCIONAIS.docx` | Lista histórias, prioridades e critérios de aceite. |
| Requisitos não-funcionais | `REQUISITOS NÃO-FUNCIONAIS.docx` | Define SLAs, requisitos de acessibilidade, LGPD, limites de performance. |
| Cardápios gerados | `Cardápio_*` PDFs | Exemplos exportados do CardapioBot usados em demos, marketing e QA. |
| Bots e pesquisas | `CardapioBotScreen.pdf`, `Caf_da_Manh_para_Hoje_.pdf`, `DOC-20251112-WA0007.pdf` | Prints e estudos de benchmark relacionados a automações/assistentes. |

## Como usar
- Consulte os requisitos sempre que surgir dúvida sobre comportamento esperado antes de abrir bug/feature.
- Use os PDFs de cardápio como referência visual para validar o export e comparar com futuras alterações no CardapioBot.
- Ao gerar novos materiais (ex.: resultados de pesquisa com usuários), salve aqui com nome data + tema para manter a trilha de auditoria.

> **Importante:** nada neste diretório é empacotado junto ao app; serve apenas como histórico para PMs, QA, marketing e compliance.
