# Referências Visuais

Repositório de capturas que servem como base para documentação histórica (slides de stakeholders, posts internos e comparativos de UX). Diferente de `mobile/assets`, estes arquivos **não** são empacotados no app.

| Arquivo | Descrição |
| --- | --- |
| `image.png` | Colagem de Configurações/VoiceRec usada em apresentações de acessibilidade. |
| Outros PNGs/JPGs | Podem incluir fluxos antigos, prints de concorrentes ou benchmarks de UI. |

## Boas práticas
- Nomeie os arquivos com o contexto (`2025-01-configs-dark.png`, `voice-rec-flow.png`) para facilitar buscas.
- Ao atualizar uma tela relevante, gere uma nova captura e substitua a referência nos documentos (`docs/`, Confluence, etc.).
- Use resoluções altas (mínimo 1280px de largura) para manter legibilidade em PDFs e projeções.

Quando citar estas imagens em Markdown, use caminhos relativos (`../imgs_ref/nome.png`) para manter links consistentes.
